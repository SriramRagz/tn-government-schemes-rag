# Tamil Nadu Government Schemes – Knowledge Graph RAG Chatbot

An AI-powered Knowledge Graph Retrieval-Augmented Generation (RAG) chatbot designed to help citizens discover and understand Tamil Nadu Government schemes.

## Project Objective

To build an intelligent chatbot that retrieves information about government schemes and provides contextual answers to citizen queries using a Neo4j Knowledge Graph.

## Official Data Source

[Tamil Nadu Government – Scheme Listing](https://www.tn.gov.in/scheme_list.php?dep_id=Mg==)

## Reference Implementation

[KG-rag-mac – Knowledge Graph RAG](https://github.com/manojkanur/KG-rag-mac)

## Technology Stack

- Python 3.13
- Neo4j
- LangChain
- OpenAI
- Neo4j Python Driver

## Planned Features

- Government scheme information retrieval
- Department-wise scheme discovery
- Eligibility and benefits information
- Document requirements
- Application guidance
- Tamil and English question answering
- Official source references

## Project Structure

The application will include modules for data ingestion, knowledge graph creation, retrieval, and chatbot interaction.
